# SARVAM
SARVAM is a web app made for post Rehabilitation for Neuro patients specific to Brain stroke and TBI, It has cognitive rehab games, 3d robo Rehab simulations, Medication slots, weather adaptive hydration coach, Personalised Diet planner, fine tuned AI gateway, Personalised step counter with metrics, and SOME (SARVAM ORAL MOTOR EXCERCISES) module
